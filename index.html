Why Kiln

Ops, not files.

Blasting whole .blend files breaks. Kiln syncs ordered operations — low latency, replayable, mergeable.

LIVE · v0.1

🔴 Live object sync

Transforms, add/remove, rename, parent — debounced to 10 Hz per object. Stable kiln_id so renames don't fork. Echo suppression, LWW + sequence numbers.

LIVE · v0.1

👥 Rooms + presence

Join demo as anand. See who's here, their selections, 3D cursors, viewport colors. Follow mode for reviews.

LIVE · v0.1

🔒 Soft locks

Claim an object before a risky edit. Others get a red banner, not a silent overwrite. Auto-released on disconnect.

LIVE · v0.1

💬 Comments + 📸 snapshots

Pin notes at the 3D cursor. Push a snapshot before chaos, pull to restore. Op log keeps last 10k for replay.

LIVE · v0.1

🛟 Friendly + debuggable

1-2-3 connect flow, Test button with fixes, Troubleshooting box, Export Log bundle, /debug/rooms endpoints, headless probe script.

NEW · v0.2

🖥️ Stdlib-only addon

No pip hell inside Blender. Custom WebSocket client on stdlib, timer-pumped on the main thread. Blender 4.2 LTS+.

Shared Compute · v0.2-alpha

Your session is the farm.

Same-session only — no accounts, no uploads. Workers already hold the scene via live sync, so jobs send params, not .blends. Toggle sharing, submit, watch it fan out.

FARM

🎞️ Frame farm

Frames 1–100 → one task per frame. Submit Frames, idle sharers auto-claim, progress bars per worker color. Timeouts + disconnects requeue seamlessly.

FARM

🧩 Tile farm

One hero frame → 2×2…5×5 tiles with border padding. GPU boxes grab tiles, CPU boxes grab frames. Composited in v0.3 blob store.

FARM

🔥 Bake offload

Physics / geometry-nodes bake → single task routed to the beefiest sharer by score. Result returns as a snapshot push.

# smart allocation — deterministic, testable
score = 10·cpu + 20·gpu + 5·mem/8 − 30·load − rtt/50
# −1000 veto: not sharing · stale >30s · Blender version mismatch
bake → max score only · frames/tiles → best waiting task per claim

Safety: room members only. v0.2 artifacts are checksums (scheduling proven); real EXR/PNG + Docker sandbox land in v0.3/v1.0. Don't farm with strangers yet.

Quickstart

Live in 2 minutes.

1 · Run the server

pip install -e ./server
kiln-server --port 8000
# → http://127.0.0.1:8000/healthz {"ok":true}

# or
docker compose up --build

2 · Join from Blender 4.2+

Zip addon/kiln → Preferences → Install from Disk → enable Kiln. Sidebar (N) → Kiln → Server ws://127.0.0.1:8000, Room demo, different Name per PC → Connect. Move a cube. Second Blender follows.

Test → Server OK (25ms)
Share my CPU/GPU → ON
Submit Frames 1-4 → 3/4 done
