Chapter I

Synchronise operations, not files.

Sending whole .blend files on every edit is slow and unmergeable. Kiln instead sends small ordered operations over WebSockets from an authoritative server. Each operation receives a sequence number; clients apply it idempotently and quietly discard their own echoes.

Every object carries a stable identifier (obj["kiln_id"], a UUID), so a rename or a reparent does not fork the scene. Transforms flush at ten hertz per object; mesh replacements — capped at fifty thousand vertices — are pushed on leaving edit mode, not per keystroke.

Table I. The operation vocabulary, v0.1.
OperationCarriesRemark
object.upsert / removeStable id, type, name, parentDeletes kept as tombstones
transformLocation, rotation, scale, visibilityPartial updates; last-writer-wins per field
mesh.replaceVertices and polygons, in fullSee cap above; snapshots for the heavy lifts
lock · presence · comment · snapshotHolder; cursor; prose; scene dumpLocks are soft; presence at two hertz

Four decisions, stated plainly. First, the server is authoritative and the clients are simple — first-seen wins the sequence. No conflict-free replicated data types yet; at two to ten users, predictability is worth more than cleverness. Second, the addon uses only the standard library for networking, because Blender's embedded Python so often lacks pip. Third, nothing touches bpy off the main thread; the network thread writes to a queue drained by a timer. Fourth, locks are advisory and released on disconnect — a red banner, not a deadlock.

“We wanted the feeling of passing a sketchbook across the table — you can see the other hand on the page.”— Design note, docs/ARCHITECTURE.md

What it will not do yet: per-vertex deltas for heavy sculpts (use snapshots); undo across machines (remote edits arrive as new operations); permissions beyond soft locks. Room members are trusted.1

Chapter II

The session is the farm.

Only machines already in the room may contribute — no outside workers, no accounts, no uploads. Because each sharer already holds the synced scene, a job is merely parameters: frames one through twenty-four; tiles two-by-two of frame seven; bake the cloth. Workers render their local copy and report back.

Table II. Three modes of shared compute, v0.2-alpha.
ModeDivisionAssignment

Tile farmGrid-squared tiles with border, in 0–1 UVGraphics machines outscore naturally
Bake offloadA single task, the whole bakeThe top-scoring sharer only; the rest wait
# The allocation score — server/src/kiln_server/compute.py
score = 10·cpu + 20·gpu + 5·mem/8 − 30·load − rtt/50
veto when: not sharing · unseen > 30 s · Blender major.minor differs

A frank caveat: this alpha reports deterministic checksums rather than pixels — sufficient to prove scheduling, allocation, requeue and progress end to end. True EXR/PNG assembly and a sandbox for untrusted farms arrive in §§IV. Until then, farm only with colleagues you trust; a .blend can execute arbitrary code.2

Chapter III

To run it.

Two terminals, two Blenders. First the server:

# the sequencer and scheduler
pip install -e ./server
kiln-server --port 8000
curl http://127.0.0.1:8000/healthz   # → {"ok": true}
  • Blender 4.2 or later: compress addon/kiln to a zip, Preferences → Install from Disk, enable Kiln Collaborative Editing.
  • Both machines: in the sidebar (N) → Kiln, enter the same server address and the same room (demo), but different names. Press Connect.
  • Verify: move the default cube; the counters should read seq … ↑n ↓m. Then, under Shared Compute, switch on Share my CPU/GPU and submit Render Frames 1–4.
  • If stuck: Test reports latency with a remedy; Export Log writes kiln-debug.txt for an issue report. Headless check: python examples/debug_probe.py.

Layout of the repository: addon/kiln/ the Blender client; server/ the FastAPI sequencer and scheduler; protocol/ the wire specifications; docs/ architecture, debugging, compute, roadmap; examples/ headless demonstrations.

Chapter V

On licensing.

The addon (addon/) is GNU GPL-3.0-or-later — necessarily so, as import bpy makes it a derivative of Blender. The full text is in LICENSE-ADDON. All else — server/, protocol/, examples/, docs/ — is Apache-2.0 (see LICENSE-SERVER), a permissive grant suited to studio self-hosting. The mapping is recorded in NOTICE; each file bears an SPDX header.
